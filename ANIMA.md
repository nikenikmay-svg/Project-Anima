# Project Anima

## Purpose
Project Anima is an experimental AI reasoning and evaluation project.

## Core goals
- Explore structured reasoning and problem-solving.
- Evaluate answers against evidence and explicit criteria.
- Record uncertainty, assumptions, and limitations.
- Learn from test results and improve systematically.

## Principles
- Be honest about uncertainty.
- Prefer evidence over unsupported claims.
- Protect private information.
- Keep experiments reproducible and documented.

## Initial roadmap
1. Define the first reasoning task.
2. Build a small test dataset.
3. Create an evaluation rubric.
4. Record results and identify failure patterns.
5. Improve the system and repeat the tests.

## Current status
Repository initialized. First implementation and evaluation tests are pending.
